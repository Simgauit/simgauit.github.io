Privacy policy

Cardiology Rota Tools is a private set of scripts run by Simar Pal Singh on his own computer. Only the rota account, cwmgcardioroster@gmail.com, signs in to it. Last updated 4 October 2026.

What the tools access

  • Gmail, read-only: to read rota messages such as leave requests and replies.
  • Gmail, compose: to create email drafts, and to send rota notices to the operator's own address only. Every other email is a draft that a person reviews and sends.
  • Google Drive, own files only: to create and update the rota files the tools themselves make.
  • Google Calendar, own calendars only: to create rota calendars and their events.

How the data is used

Data is used only to run the rota. It is processed on the operator's computer, including by the AI coding assistant he uses to run the tools. It is not sold, not used for advertising, not used to train AI models and not shared with anyone else. The sign-in token is kept on that computer and never published.

Use of information received from Google APIs follows the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

Access can be withdrawn at any time at myaccount.google.com/permissions.
