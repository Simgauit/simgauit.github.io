Cardiology Rota Tools

A private set of scripts that Simar Pal Singh uses to run a hospital cardiology rota. The tools prepare rota updates, draft emails for him to review, keep a copy of the rota on Google Drive and publish rota calendars.

The tools are not a public service. Only the rota account, cwmgcardioroster@gmail.com, signs in to them.
